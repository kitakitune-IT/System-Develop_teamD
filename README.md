# 災害安否報告システム

チームでのシステム開発を想定した授業内で製作した、『災害時の安否確認サイト』です。
自分の担当箇所はPHPファイルです。
現在の知識をもとに、Webアプリケーションにおける代表的な脆弱性と攻撃手法を想定し、セキュリティを意識した実装を行いました。

## 使用技術
- PHP 8.x(動作確認環境:8.5.5/8.4.13)
- MySQL
- HTML / CSS

## セキュリティ対策の実装箇所

本システムでは、以下の脆弱性に対する対策を実装しています。

- **SQLインジェクション対策**
  - PDOを用いた静的プレースホルダによるデータベース操作の徹底 (`db.php`)
- **クロスサイトスクリプティング (XSS) 対策**
  - 出力時のエスケープ処理 (`htmlspecialchars`) を共通関数化し、全ビューで適用 (`def.php`)
- **クロスサイトリクエストフォージェリ (CSRF) 対策**
  - `random_bytes`を用いたワンタイムトークンの生成と、POST時のトークン検証処理 (`def.php`, 各登録・編集処理)
- **アクセス制御の不備 (Broken Access Control) 対策**
  - 管理者権限の有無や、セッションの有効期限を判定する共通関数を作成し、各ファイルの先頭で検証 (`def.php`, `admin_check()`)
  - 他者の安否データを勝手に編集できないよう、更新処理前にユーザーIDの照合を実施 (IDOR対策) (`safe_Edit.php`)
- **安全なパスワード保存**
  - `password_hash()`を用いた不可逆なハッシュ化 (`employee_Regist.php`)
- **セッションハイジャック対策**
  - ログイン成功時の `session_regenerate_id(true)` によるセッションIDの再発行 (`db.php`)
